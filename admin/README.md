# admin/

Administrative documents for the research project.

## outreach/

Emails to supervisors, ethics committees, grant bodies, and other stakeholders.
These are **guarded documents** — citation integrity rules apply in full. Every
paper referenced must have a PDF in `literature/papers/` and an MKV in
`literature/mkv/`, and every claim must be verified against a quotable passage.
See [CLAUDE.md](../CLAUDE.md) for the full citation integrity rules.
